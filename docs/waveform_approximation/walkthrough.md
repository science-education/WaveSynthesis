# 成果確認 (Walkthrough)：波形近似シミュレーション (WaveSynthesis)

波形近似シミュレーション (WaveSynthesis) の実装が完了しました。
主要な機能、画面設計、および動作確認の手順を以下にまとめます。

---

## 実装された主要機能

1.  **高解像度 Canvas による波形描画**:
    - デバイスピクセル比 (`devicePixelRatio`) を自動計算し、Retinaディスプレイや高DPIモニターでも線がぼやけず、極めて滑らかで鮮明な波形アニメーションを描画します。
2.  **マイク録音と波形フレーム抽出**:
    - Web Audio API を活用し、マイクからの入力をデコード。
    - 3秒間の録音バッファから**最もエネルギー（振幅）の大きい2048サンプルのフレーム**を自動検出し、FFT解析の入力として切り出すことで、ユーザーの「声」などの特徴的な波形を安定して取得します。
3.  **高速フーリエ変換（FFT）の自作実装**:
    - JavaScript で Cooley-Tukey Radix-2 FFT アルゴリズムをゼロから実装。
    - 実数バッファから振幅および位相成分を高速に計算します。
4.  **周波数成分の抽出と個別オン/オフ機能**:
    - FFT 解析結果から**振幅の大きい上位12個の主要成分**を抽出し、周波数の低い順（基音から高調波）にリスト表示します。
    - 各成分のミニ波形（Canvas）を表示し、チェックボックスをON/OFFすることで、メイン波形の近似状態がリアルタイムで変化（加算・減算）します。
    - 個々の波の「ソロ試聴」ボタン（1.5秒間の正弦波再生）を実装し、単一の倍音がどのような音かを確認できます。
5.  **リアルタイム PeriodicWave 音声合成**:
    - チェックボックスでONにされた成分のみから `PeriodicWave` を動的に生成し、`OscillatorNode` に設定してループ再生します。
    - 成分の切り替え時にプチプチというクリッピングノイズが発生せず、極めて滑らかな音色の変化を聴き比べることができます。

## 動作確認の手順

現在、バックグラウンドでローカル Web サーバーが起動しています。ブラウザで以下のURLを開いて動作を確認できます。

**検証用URL**: [http://localhost:8080](http://localhost:8080)

> [!WARNING]
> マイクからの録音機能は、ブラウザのセキュリティ上の理由から `http://localhost` または `https://` で配信されている場合にのみ有効化されます。ローカルサーバー経由でアクセスしてください。

### テストシナリオ 1: プリセット音源の解析と合成
1.  ブラウザで [http://localhost:8080](http://localhost:8080) にアクセスします。
2.  「音源の入力と選択」パネルの「プリセットを選択」ドロップダウンから **「鋸歯状波 (ソートゥース波)」** または **「バイオリン風の音」** を選択します。
3.  メイン表示エリアに「元の波形」（ネオングリーン）と「合成波形」（ネオンマゼンタ）が完全に重なって表示されることを確認します。
4.  右側の「分解された波の要素」に、基音から倍音までの12個の波形が並んで表示されることを確認します。
5.  **「合成した音を聴く」** ボタンをクリックします。音がループ再生されます。
6.  倍音成分のチェックボックスをいくつか外してみます。
    - メイン波形から対応するギザギザが消え、滑らかな波形になっていくことを確認します。
    - 同時に、再生中の音が「シャープな音（鋸歯状波）」から「丸みのあるこもった音（サイン波に近い音）」に変化することを確認します。
7.  音量スライダーで音量が適切に変更できることを確認します。
8.  「すべて解除」を押すと波形が消え、音が消音されます。「すべて選択」を押すと元の波形と音が復元されます。

### テストシナリオ 2: マイク録音の解析と合成
1.  **「マイクで録音」** ボタンをクリックします。
2.  ブラウザのマイク使用許可ダイアログが表示されたら「許可」を選択します。
3.  「録音中... (3s)」とカウントダウンが表示されている間に、マイクに向かって一定の音高で声（例：「あーーー」）を出します。
4.  3秒後に自動的に録音が停止し、声の波形がネオングリーンで表示されることを確認します。
5.  分解された主要な周波数成分が表示されます。
6.  「合成した音を聴く」をクリックし、自分の声の倍音成分が合成された「電子音的なあ」の音が再生されることを確認します。

## プレミアムなデザインとUI/UXの特長

- **ダーク/ネオンテーマ**: 背景にはインディゴからマゼンタにかけての微細な光の広がり (`.glow-bg`) を配し、カードには半透明の `backdrop-filter: blur` を適用した美しいグラスモルフィズムデザイン。
- **直感的なタブ切り替え**: 波形を表示する「時間領域」と、周波数の強度を示す「周波数領域（スペクトル）」をタブでスマートに切り替え可能。
- **レスポンシブデザイン**: デスクトップでは操作しやすいサイドバイサイドの3カラム風レイアウト、タブレットやモバイルでは縦一列に最適化された配置に自動で切り替わります。
