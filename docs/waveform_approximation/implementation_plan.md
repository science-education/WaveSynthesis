# 実装計画：波形近似シミュレーション (WaveSynthesis)

このプロジェクトでは、音や波が複数の単純な波（正弦波）の重ね合わせで構成されていることを、視覚的・聴覚的に理解できるインタラクティブなWebアプリケーションを開発します。ユーザーは自分の声を録音するかプリセットの波形を選択し、それをFFT（高速フーリエ変換）で分解し、個別の成分をチェックボックスで選択して合成波形（近似波形）を構築・試聴できます。

---

## ユーザーレビュー要求事項

> [!IMPORTANT]
> **Web Audio APIのブラウザ制限について**
> ブラウザのセキュリティ制限により、ユーザーが画面を一度クリックまたはタップするなどのインタラクションを行うまで、音声を再生するための `AudioContext` は開始できません。アプリ起動時に「開始」または「音声を有効にする」明確なアクションを促すUI設計にします。

> [!TIP]
> **FFT分解後の成分数について**
> 2048サンプルのFFTを行うと1024個の周波数バケットが得られますが、すべての成分を画面に表示すると操作性が悪くなります。そのため、**振幅（強さ）の大きい上位10〜15の主要な周波数成分**を抽出し、個別にオン/オフできるリストとして表示します。これにより、主要な「基底の波」と「彩り（倍音）の波」の違いが明確に理解しやすくなります。

### 各ファイルの役割と実装内容

#### 1. [NEW] [index.html](file:///C:/Users/user/.gemini/antigravity/scratch/WaveSynthesis/index.html)
- アプリケーションのメイン構造。
- ヘッダー、コントロールパネル（録音/プリセット選択）、メイン可視化エリア（元の波形と合成波形の重ね合わせ、スペクトル表示）、および分解された各波のチェックボックス付きリストエリアを含みます。
- レスポンシブで洗練されたグリッドレイアウトを採用。

#### 2. [NEW] [style.css](file:///C:/Users/user/.gemini/antigravity/scratch/WaveSynthesis/css/style.css)
- **カラーパレット**: ダークネイビー（背景）、サイバーパンク風のネオングリーン（元の波形）、ネオンマゼンタ（合成波形）、ネオンシアン（UIアクセント）。
- **グラスモルフィズム**: 半透明のカード背景に `backdrop-filter: blur` を適用し、高級感を演出。
- **レスポンシブデザイン**: モバイルからデスクトップまで快適に操作可能。

#### 3. [NEW] [fft.js](file:///C:/Users/user/.gemini/antigravity/scratch/WaveSynthesis/js/fft.js)
- 実数入力に対するFFT（高速フーリエ変換）アルゴリズムの実装。
- パワー（振幅）と位相（フェーズ）の計算。
- バッファサイズ：2048（サンプリングレート44.1kHzの場合、周波数分解能は約21.5Hz）。

#### 4. [NEW] [audio.js](file:///C:/Users/user/.gemini/antigravity/scratch/WaveSynthesis/js/audio.js)
- **マイク録音**: `navigator.mediaDevices.getUserMedia` を使い、録音バッファを取得。
- **プリセット波形生成**:
  - サイン波、矩形波、鋸歯状波、三角波の計算合成。
  - 音声風の波（母音「あ」の簡易シミュレーション：基音＋特定のフォルマント周波数）。
  - バイオリン風の波（豊かな倍音構造を持つ波）。
- **音声合成再生**:
  - チェックされた周波数成分から `PeriodicWave` を動的に生成し、`OscillatorNode` で再生する、あるいは合成バッファを直接生成して `AudioBufferSourceNode` でループ再生します。リアルタイムに変更が反映されるようにします。

#### 5. [NEW] [app.js](file:///C:/Users/user/.gemini/antigravity/scratch/WaveSynthesis/js/app.js)
- 各Canvasの描画処理（波形グラフ、スペクトルグラフ、各成分のミニ波形）。
- チェックボックスのON/OFFイベント処理と、合成波形の再計算・再生更新。
- UIのインタラクション（録音開始/停止、プリセット切り替え、個別再生など）。

## 検証計画

### 自動/手動検証
1. **ブラウザでの動作検証**:
   - `index.html` をローカルサーバーで起動し、マイクからの録音が正常に動作することを確認。
   - プリセット波形を選択した際、正しいFFTスペクトルが表示されることを確認。
2. **波形合成の正確性の検証**:
   - すべての周波数成分のチェックボックスをONにしたとき、合成された波形が元の波形とほぼ一致することを確認（FFT/IFFTの正当性検証）。
   - 特定のチェックボックスを外したときに、その周波数の波がメイングラフの合成波から消え、音からもその高さの成分が消えることを確認。
3. **マルチデバイス検証**:
   - Google Chrome / Firefox / Safari (iOS/macOS) での音声出力、マイク入力、レスポンシブ表示の崩れがないか確認。
